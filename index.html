Privacy Policy & Terms of Use

Last updated: 2026-10-05

What this is

Word Study is a study tool built for a family's own kids — or a teacher's own class — to practice spelling and vocabulary words. It isn't a commercial product, it is run by an individual rather than a company, and it isn't intended for the general public to sign up for — a parent or teacher sets it up for their own household or class.

Privacy Policy

What information is collected

Only what a parent or teacher types in while setting the app up: a student's first name or nickname and grade level, a 4-digit PIN chosen for the parent dashboard, and the word lists being studied. As the app is used, it records practice statistics (which words were answered correctly, accuracy over time, streaks) and preferences (equipped avatar, theme, in-app star balance). No email address, birthdate, physical address, or payment information is ever collected, because the app never asks for any of those. If the microphone button is used to answer by speaking instead of typing, the browser's own built-in speech recognition handles that — on most browsers, that means the audio is sent to that browser maker's speech service (for example Google's, on Chrome) to be converted to text; Word Study itself never stores audio and only ever receives the resulting typed-out words back.

Where it's stored

Everything works offline, stored in the browser's local storage on that device. The app contacts Google Firebase when it loads to prepare syncing (it signs the device in anonymously — no name or account is involved), but no student data is written there until a household code is created or joined, or a school card or class key is used; a device that has done neither never sends a student's data anywhere. Once a household code is created or joined, the same information is also stored in Firebase, so it can be reached from more than one device. Access to that stored data is controlled entirely by a short code your household chooses to share — anyone given that code can see and change that household's data, the same way anyone given a shared document link could. Word lists can additionally be shared across households on purpose, using a separate "catalog code," specifically so households can share the same list with each other.

Children's privacy

This app is meant to be set up and supervised by a parent, guardian, or teacher for their own children or class, not signed up for directly by a child. No advertising, behavioral tracking, or analytics services are used, and nothing collected here is ever sold or shared with third parties. The outside services involved are Google Firebase, used strictly as private storage for any household that connects (Firebase is Google's own product, operated under Google's terms, not Word Study's), and the services that host this website (GitHub Pages and Cloudflare), which — like any web host — see ordinary visit information such as IP address in their own server logs. Neither is used here for advertising or analytics.

School classes

A school class works differently from a family household, on purpose. The teacher creates the class and enrolls students; each child gets a personal card (a QR code with a short code) and each family a separate read-only parent code. Whoever holds a child's card can open that child's practice — so cards should be kept private, and a teacher can replace a lost one, which immediately stops the old card and every device that used it. A parent code can only view that one child's progress. A teacher device can see the whole class's progress and word list. Shared classroom devices are set up with a separate key; they can read the class word list but are not tied to any child and do not show other students. Children cannot see other children's practice from their own device. The class stores a student's first name or nickname, grade, avatar, star and streak totals, per-word practice results (including up to three recent misspellings per word) and test percentages, with Google Firebase (region: US multi-region). Cards and keys are stored only as one-way hashes, so they cannot be read back from the database. The service operator can also see the stored data. There are no scheduled backups, so deleted data cannot be recovered. A teacher can remove a student's access; to have a student's stored records deleted, contact the address below.

Deleting your data

Reading a word list from a photo or pasted text (teachers/parents only). When an adult uses "Add a week's words" in the word-list editor, the photo or pasted text (a spelling list — not any student's data) is sent over an encrypted connection to this app's own server (a Cloudflare Worker), which passes it to Anthropic's Claude service to read the words and sends the words back. The photo is not saved by Word Study; Anthropic handles API inputs under its own commercial terms and does not train on them by default. Please do not photograph anything other than the word list, and keep children's faces and names out of the picture.

Clearing your browser's site data for this app removes everything stored locally on that device. If a household code was ever created or joined, or a school class was used, a copy also lives in Firebase; there is currently no self-service "delete my data" button in the app itself, so reach out using the contact info below to request that a household's or a student's stored data be deleted.

Being honest about the security model

Family households have no username-and-password accounts: access is by a shared household code. That's a deliberate tradeoff to keep the app simple for a family to use, not an oversight — it means anyone who has your household's code has full access to what's stored under it, the same as anyone holding a spare house key, so don't share it outside your family. School classes use personal cards and per-device access instead (see above), but there are still no passwords: anyone who holds a child's card, a teacher key or a class-device key can use it until it is replaced.

Terms of Use

This app is provided as-is, for personal family or classroom use, with no warranty of any kind — including no guarantee that it will always be available, that stored data will never be lost, or that it is free of bugs. It runs in part on a free tier of Google Firebase, which has its own usage limits; if those are ever exceeded the sync feature may stop working until the next day, though the app continues to work offline either way.

Please don't use the shared word-catalog feature to upload content that isn't an actual word list, or anything inappropriate, abusive, or illegal — it's meant to be shared between families using the app for its intended purpose. This app and how it works may change or be discontinued at any time without notice.

📚 Connect a Word Catalog

Word lists live in a catalog, organized by grade and week — separate from your private scores. Leave the code blank to get a private, hard-to-guess one for your household or class (recommended). Only type a code if you are deliberately sharing the same lists with another family or class — anyone who knows a catalog code can change its words, so never use a guessable name like your school's. Their scores stay completely separate from yours either way.

If the code doesn't exist yet, it'll be created. Leave it blank to get a private one just for your household.

📚 Manage Word Catalog

One shared catalog can hold every grade in a whole school side by side. Paste a whole year at once — start each grade with a line like GRADE 7 (starts 2026-09-01), then list words for each week — separate weeks with a blank line. Add a comma and a definition for vocab practice. Paste as many GRADE blocks as you need in one go, one per grade. Fixing just one week later? Add a WEEK 4 line right before it so it updates that week instead of week 1 — "✏️ Edit" below fills this box in correctly.
